# SkinLoop 화면별 생성 프롬프트 (Claude Design)

각 프롬프트 앞에 **공통 프리앰블**을 붙여 생성한다. 지표·문구는 스펙과 규칙을 이미 반영했다.

---

## 공통 프리앰블 (매 프롬프트 앞에 붙일 것)

```
SkinLoop 모바일 앱 화면을 만들어줘. 첨부한 Design System을 반드시 따른다.
- 프레임: iPhone 세로(393x852), 모바일 우선, 데스크톱은 max-width 480px 중앙 정렬.
- 로고 워드마크는 세리프 "SkinLoop"로 통일. 하단 탭 4개: 홈 / 기록 / 인사이트 / 내 기록.
- 톤: 연분홍 웜 크림 배경, 부드럽고 신뢰감 있게. 위계·대비·간격(8pt)을 명확히.
필수 규칙(위반 금지):
1) 점수·예측은 점추정 금지, 항상 범위로. 예: "72점" 대신 "68~74".
2) 단정·의학 표현 금지. "원인" 대신 "연관 가능성이 높은 요인", "좋아지는중" 대신 "유사한 흐름".
   진단명·질병명·치료법 금지.
3) 생활습관은 5개만: 수면 / 야식 / 스트레스 / 운동 / 화장품 변화.
   피부 상태는 3개만: 붉은기 / 트러블 개수 / 유분감. (물·세안·수분·탄력·건조함 등 스펙 밖 지표 금지)
4) 분석·결과가 있는 화면은 하단에 고지 캡션:
   "본 분석은 통계적 연관성을 보여주는 참고 자료이며 의학적 진단이 아닙니다."
```

---

## 1. 홈 — 기록 충분(7일 이상)

```
[공통 프리앰블]
홈 화면. 위에서 아래로:
- 상단: 로고 SkinLoop(좌) + 알림 벨(우).
- 인사말 H2 "오늘도 기록했나요?".
- 오늘 요약 카드: 왼쪽 원형 아바타/스코어 링, 오른쪽에 "오늘 예상 점수 68~74"(범위로),
  아래 보조문구 "어제와 비슷한 흐름이에요"(단정 금지). 하단에 primary 버튼 "기록하기".
  (오늘 미기록이면 점수 대신 "아직 오늘 기록 전이에요" + 같은 버튼)
- 인사이트 배너 카드: "새 인사이트가 준비됐어요" + secondary 버튼 "인사이트 보기".
- 내 기록 현황 카드: "12일째 기록 중" + 최근 7일 체크 인디케이터(요일 라벨 월~일, 완료 원).
7일 이상 사용자이므로 '샘플로 둘러보기' 배너는 넣지 않는다(인사이트로 유도).
```

## 2. 홈 — 기록 부족(1~6일)

```
[공통 프리앰블]
홈 화면(기록 부족 상태). 1번과 레이아웃 동일하되:
- 오늘 요약 카드: 점수 대신 "기록이 7일 모이면 패턴 분석이 시작돼요 · 앞으로 N일" 진행 안내 + 진행 바.
- 하단에 샘플 배너 카드: "먼저 둘러보고 싶다면? 28일치 샘플로 미리 확인해보세요"
  + secondary 버튼 "28일 샘플 보기". (개수는 반드시 28일로 통일)
```

## 3. 기록 (/record)

```
[공통 프리앰블]
오늘의 기록 입력 화면. H1 "오늘의 기록".
- 섹션 "생활습관"(카드): 수면 시간 슬라이더(0~14시간), 야식 토글, 스트레스 5칸 세그먼트(1~5),
  운동 시간 슬라이더(0~120분), 화장품 변화 토글.
- 섹션 "피부 상태"(카드): 붉은기 5칸(1~5), 트러블 개수 5칸(1~5 구간), 유분감 5칸(1~5).
- 섹션 "사진(선택)": 업로드 영역.
- 하단 고정 primary 버튼 "저장".
- 같은 날 이미 기록이 있으면 "오늘 기록은 이미 저장됐어요, 수정할까요?" 안내(중복 처리).
점수 계산·표시는 이 화면에서 하지 않는다(저장 후 서버 계산).
```

## 4. 분석 중 (/analyzing) — 선택

```
[공통 프리앰블]
로딩 화면. 중앙 진행 애니메이션 + "기록을 살펴보고 있어요". 최대 5초 대기 느낌.
간결하게, 카드 없이 배경 위 중앙 정렬.
```

## 5. 인사이트 (/insight)

```
[공통 프리앰블]
피부 인사이트 화면. H1 "오늘의 피부 인사이트".
- 상단 우측에 confidence 뱃지(기록 일수 기반: low/medium/high) + "최근 N일 기록 기준".
- 카드 "연관 가능성이 높은 요인"(상위 3개만): 각 항목을 가로 영향도 막대로. 예: 수면 부족 / 스트레스 / 야식.
  (5개 나열 금지, 상위 3개. "원인"이라는 단어 금지)
- 카드 "인사이트": 2문장 이내 문장. 예 "수면 부족과 붉은기가 함께 나타나는 패턴이 보여요.
  꾸준히 기록하면 더 또렷해져요." (단정·의학 표현 금지)
- 카드 "왜 이렇게 분석됐나요?": 근거 일자와 수치(예: 점수가 낮았던 날짜 3개).
- 하단 primary 버튼 "시나리오 비교하기"(대비 충분, 비활성처럼 보이지 않게).
- 최하단 고지 캡션 필수.
기록 부족(<7일) 변형: 요인 카드 대신 "앞으로 N일 더 기록하면 분석이 시작돼요" + "28일 샘플 보기".
```

## 6. 시나리오 비교 (/whatif)

```
[공통 프리앰블]
시나리오 비교 화면. H1 "시나리오 비교", 서브 "어떤 습관을 바꿔볼까요?".
- 습관 선택 칩(라벨 채우기): "수면 +1시간" / "야식 줄이기" / "스트레스 낮추기" / "운동 늘리기".
- 결과 카드: 4주(주간 평균 4포인트) 라인 차트. 계열 2개 "현재 유지" vs "변경",
  각 계열에 min~max 범위 밴드. 점추정 금지, "4주 뒤 60~66 범위로 유사한 패턴" 식 표기.
- 요약 문구: "변경 시 유사한 개선 흐름이 보여요(범위로 제시)" 같은 비단정 표현.
- 하단 primary 버튼 "이 실험 시작하기"(14일 실험 제안).
- 최하단 고지 캡션 필수.
```

## 7. 내 기록 / 캘린더 (+실험 결과)

```
[공통 프리앰블]
내 기록 화면. H1 "내 기록".
- 캘린더 카드: 월 표시 + 요일 헤더(일 월 화 수 목 금 토), 해당 월 전체 일수(예: 10월=31일).
  기록 있는 날은 채움/점으로 표시, 선택한 날은 테두리 강조. 날짜 탭 시 상세로 이동.
- 주간 요약 카드: 평균 점수(범위로, 예 "70~74"), 수면 평균, 스트레스 평균, 운동 평균.
  (수분·물 등 스펙 밖 지표 금지)
- 실험 결과 카드: 피부 지표(붉은기 / 트러블 / 유분감)의 변화 "경향"을 범위/방향으로,
  단정 금지. 판정은 improved/no_change/needs_more를 부드럽게:
  "개선 경향" / "큰 변화 없음" / "판단엔 기록이 더 필요해요".
- 최하단 고지 캡션 필수.
```

---

## 생성 팁

- 화면은 위 순서(홈 → 기록 → 인사이트 → 시나리오 → 내 기록)로. 홈 2종은 상태 변형으로 함께.
- 결과가 스펙 밖 지표를 만들면 "생활습관 5개/피부 3개만" 규칙을 다시 강조해 재생성.
- 문구가 단정적으로 나오면 "범위·경향, 의학 표현 금지"를 재강조.
