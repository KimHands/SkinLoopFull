## P1 핵심 기능 UI — 반영됨 ✅

- **인사이트**: 연관 요인 **상위 3개** + 가로 영향도 막대(수면 86% · 스트레스 62% · 야식 38%),
  confidence 뱃지(`medium` + "최근 12일 기준"), "왜 이렇게 분석됐나요?" 근거 3일.
- **시나리오**: 습관 칩 4종 + **현재 유지 vs 변경** 2계열 라인 + **범위 밴드(min~max)**,
  요약 카드 두 범위 비교, 14일 실험 CTA. 점추정 없음.
- **기록**: 입력 폼 완비(수면·운동 슬라이더, 야식·화장품 토글, 스트레스·붉은기·트러블·유분감 5칸 세그먼트),
  중복 기록 안내, 사진 선택.
- **내 기록/캘린더**: 요일 헤더 + 31일 + 기록일/선택 상태 색 구분 + 범례. 주간 요약(범위), 실험 결과(경향).

## P2 비주얼 — 대체로 정리됨 ✅

## 남은 소소한 개선점 (있으면 좋음, 필수 아님)

1. **트러블 개수 세그먼트 라벨**: 값은 1~5인데 의미(거의없음~10개 이상)는 선택 시 힌트로만 보임.
   각 칸 아래 미니 라벨을 상시 노출하면 이해가 빠름. (스펙: `skin_acne_count` 1~5 구간값 — 현 구현 정합)
2. **"이번 주 요약" vs 월 캘린더**: 같은 카드 흐름에 주간/월이 섞임. 제목을 "요약(최근 7일)"로
   명확히 하거나 기간 토글 추가 고려.
3. **secondary 버튼 대비**: 핑크 글자(#C76D80) on 연핑크(#F7DEE4)는 AA 경계. 시연 화면 크기에선
   충분하나, 실제 구현 시 명도대비 4.5:1 확인 권장.
4. **상태바 "9:41"** 목업 장식 — 실제 구현에선 시스템 상태바로 대체(문제 아님).
5. **알림 벨 아이콘** 동작 미정 — 로그인 없는 서비스라 알림 소스가 뭔지 정의 필요
   (없으면 제거해도 무방).
6. **시나리오 범위 밴드**가 데이터 목업상 ±3.5 고정 근사 — 실제 whatif 응답의 트리 표준편차
   기반 range로 교체 필요(05-ai-module 계약).

## 스펙 정합성 메모

- whatif 대상 4종(수면·야식·스트레스·운동)만 노출 — `cosmetic_changed` 제외 규칙과 일치 ✅
- 근거 일자 = 점수 낮은 3일 — HabitPattern evidence_dates 설계와 일치 ✅
- confidence 뱃지 표기(low/medium/high) — 04-api 기준 존재 ✅

## 결론

**그대로 시연·구현 착수 가능한 수준.** P0/P1은 충족됐고, 위 6개는 실제 FE 연동(`skinloop-fe`)
단계에서 실데이터에 맞추며 정리하면 되는 항목이다. 이 목업을 화면 스펙(SSOT)으로 삼아
컴포넌트(세그먼트·토글·영향도 막대·범위 밴드 차트·캘린더 셀)를 그대로 옮기는 것을 권장한다.
