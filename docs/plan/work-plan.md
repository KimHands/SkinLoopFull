## 개발 규칙 (web.md)

- **TDD**: 기능 구현 전 실패하는 테스트 먼저.
- DB는 read-only 계정 연결. **스키마 변경·마이그레이션은 사람이.**
- 배포 트리거(PR 머지/배포 명령)는 매번 명시적 확인.
- 브라우저 확인은 `gstack` 명시 호출.
- 리뷰: `/code-review` → code-simplifier·static-analysis 순.
- 모든 작업은 **브랜치 + PR**, main 직접 커밋 금지(골격 초기 세팅은 예외로 직커밋함).
