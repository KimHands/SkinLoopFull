# feat/frontend-complete

## 목적

API 연결, 반응형 레이아웃, 핵심 화면, 통합 QA와 홈 카드 간격 조정까지 포함한 프론트엔드 최종 완성본을 관리한다.

## 브랜치 관계

- 기준 브랜치: `chore/integration-qa`
- 기존 브랜치명: `fix/home-card-spacing`

## 작업 내용

- 이전 프론트 기능 브랜치의 작업 전체 포함
- 로컬 통합 검증 디렉터리 `.tmp/`를 Git 추적 대상에서 제외
- 필수 API 환경변수 예제와 프로젝트 실행 README 추가
- 미사용 Recharts 의존성, 기본 SVG 자산, `/experiment` 리다이렉트 제거
- 사진 미리보기 Object URL 정리 및 Next Image 적용
- 시나리오 그래프 자동 스케일과 현재·변경 범위 밴드 추가
- 주요 프론트 파일 Prettier 포매팅
- 홈 요약 카드 내부를 세로 flex 레이아웃으로 정리
- 텍스트 요소 기본 margin을 제거하고 12px 간격 적용
- 설명과 CTA 사이에 추가 여백 적용
- 최종 모바일 디자인 시안의 색상, 카드, 상태바, 하단 내비게이션 반영
- 태블릿 2열 입력 폼과 PC 사이드 내비게이션 반응형 구성
- 라우트 파일과 화면 구현을 분리하고 `components/{페이지명}` 구조 적용
- 기록 척도·토글, 홈 주간 진행도, 시나리오 그래프, 기록 캘린더를 페이지별 하위 컴포넌트로 분리
- 기존 세션·기록·패턴·시나리오·샘플 API 연결 및 오류 폴백 유지

## 검증

- 홈의 기록 카드와 분석 진행도 카드에서 동일한 간격 적용 확인
- ESLint 오류 0개
- Next.js production build 성공
- `origin/feat/backend-core` 실제 API 통합 검증 완료
