# feat/record-screen
## 목적
생활습관 5개와 피부 상태 3개를 기록하고 백엔드 저장 결과에 따라 다음 화면으로 이동한다.
## 브랜치 관계
- 기준 브랜치: `feat/home-screen`
## 작업 내용
- 반응형 기록 폼과 기본값
- `POST /api/records` 연결
- `patternReady`에 따른 홈·분석 화면 분기
- 409 중복 날짜 안내
- 네트워크 오류 시 localStorage 임시 저장
- 사진 로컬 미리보기(백엔드 업로드 계약 없음 명시)
## 검증
- 통합 QA에서 저장 성공·중복·오프라인 초안 복구 확인 예정
