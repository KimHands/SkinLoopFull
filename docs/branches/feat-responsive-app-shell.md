# feat/responsive-app-shell

## 목적
모바일 레퍼런스의 디자인 언어를 유지하면서 태블릿과 PC에서 공간을 활용하는 공통 레이아웃을 제공한다.

## 브랜치 관계
- 기준 브랜치: `feat/session-store`
- API와 세션 브랜치 위에 쌓는 스택 브랜치

## 작업 내용
- 디자인 토큰, 카드, 버튼, 폼, 그리드 공통 스타일
- 모바일 하단 탭, 태블릿 확장형 탭, PC 사이드 내비게이션
- 샘플 모드 상단 배너
- 768px·1200px 반응형 구간
- 분석 화면에서 재사용할 고지 컴포넌트 스타일

## 검증
- 360px, 768px, 1440px 화면 폭에서 최종 통합 QA 예정

## 후속 작업
- 홈, 기록, 인사이트, 시나리오, 내 기록 화면 구현
