# 00. 개요

> 원본: `spec.md` §1

## 한 줄 정의

생활습관과 피부 상태를 함께 기록하고, 둘 사이의 상관 패턴을 찾아 사용자가 직접 검증하게 하는 웹 서비스.

## 무엇을 만드는가

- 매일 **1분 안에** 생활습관(수면·야식·스트레스·운동·화장품)과 피부 상태(붉은기·트러블·유분감)를 기록.
- 기록이 **7일 이상** 쌓이면 어떤 습관이 피부 변화와 반복적으로 연관되는지 분석해 보여준다.
- 습관 하나를 바꿨을 때 **4주 뒤** 어떻게 달라질지 시나리오로 비교해 준다.

## 핵심 제약

| 제약 | 내용 | 영향받는 문서 |
| --- | --- | --- |
| 로그인 없음 | 회원가입·로그인 화면 없음. localStorage 익명 UUID로 식별 | 04-api, 07-screens |
| 모바일 우선 | 세로 화면 기준. 데스크톱은 max-width 480px 중앙 정렬 | 07-screens |
| 개발 기간 5일 | 핵심 기능 3개만 구현 | work-plan |
| 의학적 표현 금지 | 진단명·질병명·치료법 불가. "원인" 대신 "연관 요인" | 08-conventions |

## 핵심 기능 3개

| 순번 | 기능 | 설명 | 관련 API | 화면 |
| --- | --- | --- | --- | --- |
| ① | 데일리 스킨 체크인 | 로그인 없이 1분 안에 오늘의 습관·피부 기록 | POST /api/records | /record |
| ② | 원인 후보 패턴 분석 | 누적 기록에서 영향 가능성 높은 습관을 순위로 제시 | GET /api/patterns | /insight |
| ③ | 습관 변경 시나리오 비교 | 습관 하나를 바꿨을 때 4주 뒤 변화 범위를 현재 유지와 비교 | POST /api/whatif | /whatif |

## 성공의 최소 조건

기능 ②③은 기록이 쌓여야 확인 가능하므로, **28일 시드 데이터**(06-seed)가 데모/검증의 전제다.
자세한 완료 기준은 [08-conventions.md](08-conventions.md#완료-기준) 참조.
