# 08. 표현 규칙 · 범위 · 완료 기준

> 원본: `spec.md` §10·11·12

## 표현 규칙 (코드·UI 문구 전반)

| 규칙 | 예시 |
| --- | --- |
| "원인"이라고 쓰지 않는다 | "연관 요인", "영향 가능성이 높은 요인" |
| 진단명·질병명·치료법 금지 | "여드름 치료" 불가 |
| 점 추정치를 쓰지 않는다 | "63점" ✕ → "60~66" ○ |
| 예측이 아니라 시나리오 | "4주 뒤 이렇게 됩니다" ✕ → "유사한 패턴을 보입니다" ○ |
| 화면 하단 고지 | "본 분석은 통계적 연관성을 보여주는 참고 자료이며 의학적 진단이 아닙니다" |

→ 이 규칙들은 `AGENTS.md`에도 요약되어 프로젝트 전역에 적용된다.

## 구현하지 않는 것

| 항목 | 사유 |
| --- | --- |
| 로그인·회원가입 | 익명 토큰으로 대체 |
| 사진 업로드·S3 | 분석에 안 쓰는데 비용 큼 (P2) |
| 사진 기반 AI 자동 점수화 | 학습 데이터 없음 |
| 제품 추천 | 서비스 방향과 다름 |
| 커뮤니티·공유 | P2 |
| 푸시 알림 | 웹 기반이라 제외 |
| 다국어 | 한국어만 |
| 생리주기 입력 | 민감 건강정보, 별도 동의 필요 |

## 완료 기준

### 최소 통과 (서비스 성립)

```
[ ] 배포 URL로 접속된다
[ ] 로그인 없이 바로 기록 입력 화면에 들어간다
[ ] 기록을 저장하면 skin_score가 나온다
[ ] 샘플 버튼 1회로 28일치가 적용된다
[ ] 샘플 모드에서 인사이트 화면에 영향도 막대 3개가 뜬다
[ ] AI 응답이 실패해도 폴백 문장이 뜬다
```

### 완전 통과

```
[ ] 위 전부 + 시나리오 비교 그래프가 뜬다
[ ] 기록 7일 미만일 때 진행도 표시
[ ] 실험 결과 화면이 샘플 모드에서 보인다
[ ] 모바일 세로에서 레이아웃 안 깨짐
[ ] 다른 브라우저에서도 정상 동작
```
