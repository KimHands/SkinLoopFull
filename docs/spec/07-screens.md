# 07. 화면 명세

> 원본: `spec.md` §8 — ASCII 목업의 정본은 spec.md.

## 공통

- 화면 6개. **모바일 세로 기준**, 데스크톱은 max-width 480px 중앙 정렬(`app/layout.tsx`에 적용됨).
- 샘플 모드일 때 모든 화면 상단에 "샘플 데이터 체험 중 [내 기록으로]" 배너 고정.

## 정보구조

```
홈
├─ 기록 입력
├─ 분석 중 (로딩)
├─ 인사이트
│   └─ 시나리오 비교
└─ 실험 결과 (샘플 모드)
```

## 화면별 요약

| # | 라우트 | 핵심 | 주요 동작 |
| --- | --- | --- | --- |
| 1 | `/` | 홈 | 최초 진입 시 UUID 생성 + POST /session. 기록 유무로 분기. 샘플 버튼 항상 노출 |
| 2 | `/record` | 기록 입력 | 한 화면(스텝 없음), 1분 목표. 전부 기본값 → 안 만져도 저장 가능. 409면 덮어쓰기 확인 |
| 3 | `/analyzing` | 분석 중 | GET /patterns 대기, 최대 5초. 타임아웃 시 폴백 진입 |
| 4 | `/insight` | 인사이트 | 영향도 Recharts 가로 막대 상위 3. 폴백이면 문장 아래 안내+재시도, **막대는 유지** |
| 5 | `/whatif` | 시나리오 비교 | 습관 칩 선택 → POST /whatif. 2선 LineChart + range 음영. **점 추정치 금지** |
| 6 | `/experiment` | 실험 결과 (P1) | 샘플 모드에서만. 전/후 평균·변화·verdict |

## 기록 입력 컴포넌트 (화면 2)

| 항목 | 컴포넌트 | 범위 | 기본값 |
| --- | --- | --- | --- |
| 수면 시간 | 슬라이더 | 0~14, 0.5 단위 | 7.0 |
| 야식 | 2지 선택 | boolean | 안 먹음 |
| 스트레스 | 슬라이더 | 1~5 | 3 |
| 운동 | 슬라이더 | 0~120분, 10분 단위 | 0 |
| 화장품 변경 | 2지 선택 | boolean | 없음 |
| 붉은기 | 5점 라디오 | 1~5 | 3 |
| 트러블 개수 | 5점 라디오 | 1~5 (0 / 1~2 / 3~5 / 6~10 / 10+) | 2 |
| 유분감 | 5점 라디오 | 1~5 | 3 |

- ⚠️ 운동 상한 120(화면) vs 300(DB/Pydantic) 불일치 ([open-questions](../plan/open-questions.md)).

## 실패 경로

| 상황 | 처리 |
| --- | --- |
| 기록 7일 미만 | 진행도 "n/7" + 샘플 버튼 노출 |
| AI 실패·타임아웃 | 폴백 문장 + 재시도. 그래프는 유지 |
| 필수 항목 미입력 | 해당 항목 하이라이트(기본값 있어 거의 없음) |
| 네트워크 오류 | localStorage 임시 저장 + 재시도 |
| 같은 날 중복 | "오늘 기록을 수정할까요?" 확인 후 덮어쓰기 |
